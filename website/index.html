Questions?

Is FindPal free?

Yes. Everything listed under Free stays free. FindPal Pro will add extras like searching text in screenshots and AI answers; core search is never locked.

Does FindPal read my files or messages?

It reads file names and folders to build a search index on your phone, not what's inside them. Notifications are only kept if you turn that on, for 7 days, on your phone.

Does it need the internet?

No. Search works offline. The only network request downloads public exchange rates when you convert a currency, and you can switch that off.

Do I have to change my home screen?

No. FindPal is a normal app. Open it from the widget, the Quick Settings tile, the assistant gesture (long-press Home or swipe from a corner) or the app icon.

Which phones does it work on?

Android 8.0 and newer, including Samsung, Xiaomi, Pixel, OnePlus, vivo and OPPO phones.

Is FindPal on iPhone?

Not yet. iPhone doesn't let apps search other apps' data the way Android does, so FindPal is Android-first.
